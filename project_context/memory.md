- **Подключение amoCRM.** Пользователь создал внешнюю интеграцию и долгосрочный токен; токен сохранён как сетевой секрет облачной среды для `gres16.amocrm.ru`. Аккаунт: K-truck.
- **Решение:** выгружать все сделки без ограничения по датам (пользователь не указал период) → 7 009 сделок с апреля 2024.
- **Находка:** звонки Telphin хранятся в карточках контактов, а не сделок → написан `link_notes.py` (звонок относится к последней созданной сделке контакта).
- **Решение по звонкам:** расшифровать выборку (не все 9 500): по одному самому длинному свежему звонку на сделку, до 5 минут, 40 выигранных и по 15 на каждую причину отказа; модель Whisper large-v3-turbo (лучше small по качеству, ~4× реального времени на 4 CPU).
- **Отчёт по сделкам** опубликован как интерактивный (тип «Data») — https://claude.ai/artifact/M9zGLLew3xwm5L2z9UjRMJ; затем по просьбе пользователя — Google Док и автономная HTML-страница.
- **База вопросов** — по просьбе пользователя в Google Таблице; сначала создана через Drive (коннектора Sheets не было), позже обновляется на месте через коннектор Google Sheets.
- **ChatApp:** токен получается по почте, паролю и appId, живёт 24 часа. Форма сетевого секрета добавляет «Bearer», а ChatApp его не принимает → секрет удалён, токен передавался переменной окружения на время выгрузки. Пользователь вставил токен и refreshToken в чат — рекомендовано сменить пароль API.
- **Находка:** ChatApp хранит историю только последние месяцы (в основном октябрь–ноябрь 2026).
- **Путеводитель для ИИ** — `reports/k-truck-ai-guide.md` + `k-truck-ai-qa.jsonl`.
- **Звонки по проигранным сделкам** дали два ключевых вывода: анкета вместо цены и расхождение цен сайта и менеджеров.

## 21.11.2026

- **Экспорт Telegram** получен по публичной ссылке на папку Google Диска (HTML, 1 246 чатов). Скачан скриптом через публичный просмотр папок без API.
- **Решение:** из анализа клиентов исключены публичные группы («Куплю Запчасти», «Запчасти на спецтехнику из Европы и США»), внутренний чат «K-TRUCK Задачи» и личный чат; комментарии канала использованы для раздела «маркетинг и репутация».
- **Отчёт** «Анализ переписки Telegram K-truck» — Google Док.
- **Риски, о которых сообщено пользователю:** оплата на личные карты, мошенники от имени K-truck, папка с перепиской открыта по ссылке (рекомендовано закрыть доступ).
- **База вопросов** расширена до 44 вопросов и 33 разборов ответов (метки [Звонок], [Переписка], [Telegram]); частоты пересчитаны с учётом Telegram.
- **Создана база знаний проекта** `project_context/` и `CLAUDE.md`.

- **История сделок из Google Таблицы** (таблица учёта компании, 4 формата листов). Скачана по ссылке в `data/deals_history/history.xlsx`, разобрана скриптом `amo_analytics/deals_history.py` в таблицу `hist_deals`.
- **Решение по дублям:** правило пользователя «одна фамилия = одна сделка». Склейка по номеру договора отключена: номер = последние 4 цифры телефона клиента и совпадает у разных людей (а префикс 2249 есть почти у всех). Строки без фамилии присоединяются по номеру договора, только если он однозначен. Фамилии на «-ич» (Бабич) не путать с отчествами.
- **Решение по суммам:** сумма сделки = «Сумма сделки», если есть, иначе сумма платежей с одного листа (не складывать листы между собой). Суммы «Лист1» (2024) — по словам пользователя, доход по сделке за вычетом расходов (поле `profit`); соседняя колонка ≈ 10% дохода (поле `bonus`) — пользователь не помнит её смысл, решено в расчёты не брать. В выручку не включаются. Номера инвойсов и текст в этих колонках отбрасываются.
- **Находка:** около 40% завершённых сделок из таблицы нет в amoCRM или они закрыты в amoCRM как проигранные.
