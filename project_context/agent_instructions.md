# Инструкции для ИИ-агентов, работающих над проектом

Прочитайте перед работой: `README.md` (структура), `knowledge_base.md` (факты), `memory.md` (что уже решено). После работы допишите `memory.md`.

## Роли агентов

| Роль | Задача | Главные файлы |
|---|---|---|
| Аналитик данных | Выгрузка и пересчёт метрик | `amo_analytics/*.py`, `data/amo.sqlite` |
| Аналитик переписки | Темы, возражения, разбор ответов | `chat_analysis.py`, `tg_analysis.py`, `knowledge_base.py` |
| Редактор отчётов | Обновление Google Доков, таблицы, интерактивного отчёта | ссылки в `README.md` |
| ИИ-консультант (продажи) | Ответы клиентам | `reports/k-truck-ai-guide.md` — системный промпт и база |

## Правила

1. **Персональные данные.** Сырые выгрузки (amoCRM, ChatApp, Telegram, расшифровки) хранятся только в `data/` и никогда не коммитятся. В отчёты и `reports/` — только обезличенные выводы: без имён клиентов, телефонов, адресов, e-mail.
2. **Секреты.** Токены amoCRM и ChatApp не пишутся в код, репозиторий и чат. amoCRM — сетевой секрет облачной среды (прокси подставляет заголовок, в коде `AMO_TOKEN=proxy-injected`). ChatApp — токен на 24 часа через переменную `CHATAPP_TOKEN` на время запуска. Если пользователь вставил токен в чат — предупредить и попросить сменить пароль API.
3. **Не выдумывать цифры.** Каждая цифра в отчёте берётся из `data/*.json` или запроса к `data/amo.sqlite`. Оценки по ключевым словам помечать как оценки.
4. **Изменения в Google-файлах** — только в существующих файлах (ссылки не меняются). Перед правкой прочитать файл; после правки перечитать и проверить.
5. **Цены** в ответах клиентам — только как ориентир с оговоркой о курсе; точная сумма — от менеджера.
6. **Язык** — русский, коротко и по делу, без канцелярита.
7. **Git** — работать в ветке `claude/magical-meitner-bcrtbu`, коммитить скрипты и `reports/`, не коммитить `data/`.

## Пайплайн (порядок запуска)

```bash
AMO_SUBDOMAIN=gres16 AMO_TOKEN=proxy-injected python3 amo_analytics/export.py   # сделки, заметки, задачи, события
python3 amo_analytics/link_notes.py                                              # звонки контактов → сделки
python3 amo_analytics/analyze.py                                                 # data/metrics.json
python3 amo_analytics/transcribe.py                                              # выборка звонков (долго, ~2 ч на 100 звонков)
python3 amo_analytics/reasons.py                                                 # реальные причины отказов
CHATAPP_TOKEN=<токен> python3 amo_analytics/chatapp_export.py                     # переписка ChatApp
python3 amo_analytics/chat_analysis.py                                           # метрики ChatApp
python3 amo_analytics/tg_download.py <id папки Google Диска>                      # экспорт Telegram (HTML)
python3 amo_analytics/tg_parse.py && python3 amo_analytics/tg_analysis.py        # Telegram: разбор и метрики
python3 amo_analytics/deals_history.py                                           # ручная таблица сделок → hist_deals (xlsx в data/deals_history/)
python3 amo_analytics/knowledge_base.py                                          # база вопросов → SQLite + xlsx
python3 amo_analytics/report_data.py && python3 amo_analytics/html_report.py     # наборы данных и HTML-отчёт
python3 amo_analytics/ai_guide.py                                                # путеводитель ИИ и JSONL
```

Зависимости: `requests`, `faster-whisper`, `numpy`, `openpyxl`, `beautifulsoup4`, `lxml`, `ffmpeg`.

## Как обновлять базу вопросов

1. Добавить вопрос в `KB` в `amo_analytics/knowledge_base.py`: тема, вопрос, ответ, регулярное выражение для подсчёта частоты.
2. Разбор ответа — в `ANSWERS`: ситуация (с меткой `[Звонок]`, `[Переписка]` или `[Telegram]`), что сказал менеджер, оценка 1–5, как лучше.
3. Запустить `knowledge_base.py`, `report_data.py`, `ai_guide.py`.
4. Обновить Google Таблицу (вставить строки, пересчитать колонку частоты), датасеты `kb` и `answers` интерактивного отчёта.

## Правила для ИИ-консультанта, отвечающего клиентам

Полный системный промпт — в `reports/k-truck-ai-guide.md`. Кратко:
- сначала цена или вилка до города клиента, потом один вопрос;
- уточнять город и нужны ли документы (ЭПСМ);
- не обещать наличие, рассрочку, кредит, лизинг;
- отвечать на каждый вопрос клиента по порядку;
- оплата только на р/с ООО или QR с чеком;
- передавать менеджеру: договор и оплата, скидки, статус заказа, жалобы, нестандартные расчёты.
